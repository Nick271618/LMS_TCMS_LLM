# Задание 2. Регистрация нового пользователя

## Объект тестирования

Форма регистрации `/register`.

## Поля формы

| Поле | Правила |
|------|---------|
| Email | Обязательное, уникальное, формат email |
| Имя | Обязательное, 2–50 символов |
| Пароль | Обязательное, минимум 8 символов |
| Подтверждение пароля | Должно совпадать с паролем |
| Роль | «Студент» или «Преподаватель» (выпадающий список) |
| Кнопка «Зарегистрироваться» | |

## Требования

### Успешная регистрация

- При уникальном email и корректных полях:
  - пользователь создаётся;
  - выполняется автоматический вход;
  - открывается главная страница `/`;
  - отображается приветствие с введённым именем.

### Ошибки (выберите один сценарий)

1. **Email уже занят** — регистрация с email существующего пользователя → «Этот email уже зарегистрирован», на `/register`.
2. **Пароли не совпадают** → «Пароли не совпадают», регистрация не выполняется.
3. **Короткий пароль** (менее 8 символов) → «Пароль должен быть не короче 8 символов».

## Вне scope

- Подтверждение email по ссылке (не реализовано).
- CAPTCHA.

## Что сдать

Один тест-кейс на выбранный сценарий. Шаги — в повелительном наклонении, нумерованный список.
