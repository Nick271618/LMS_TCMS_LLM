# Задание 1. Вход пользователя в веб-приложение «Учётная запись»

## Объект тестирования

Форма входа на странице `/login`.

## Описание системы

Веб-приложение для учёта задач. Пользователь входит по **email** и **паролю**. После успешного входа открывается страница «Мои задачи» (`/tasks`).

## Элементы формы

| Поле | Правила |
|------|---------|
| Email | Обязательное, формат email |
| Пароль | Обязательное, минимум 8 символов |
| Кнопка «Войти» | Отправляет форму |

## Требования к поведению

### Успешный вход (позитивный сценарий)

- При **верном** email и пароле существующего активного пользователя:
  - отображается страница «Мои задачи»;
  - в шапке видно имя пользователя;
  - cookie сессии установлена (пользователь остаётся в системе после обновления страницы).

### Ошибки (негативные сценарии — выберите один для тест-кейса)

1. **Неверный пароль** — email существует, пароль неверный → сообщение: «Неверный email или пароль», остаёмся на `/login`.
2. **Пустой email** — поле email пустое → под полем: «Укажите email», вход не выполняется.
3. **Некорректный формат email** — например `user@` → под полем: «Некорректный email».

## Вне scope (не тестировать в этом задании)

- Регистрация, восстановление пароля, вход через соцсети.
- Блокировка после N попыток (не реализовано).

## Что сдать

Один тест-кейс на **один** сценарий из раздела «Требования» (позитивный или один негативный). Укажите в названии, какой сценарий проверяете.
