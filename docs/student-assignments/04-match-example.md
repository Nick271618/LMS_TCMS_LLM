# Пример задания «Сопоставление» (для преподавателя)

## Условие (вставить в шаг `match`)

Соотнесите термины тестирования с определениями.

## Пары (в редакторе шага)

| Левая колонка | Правая колонка |
|---------------|----------------|
| Тест-кейс | Документ с шагами и ожидаемым результатом |
| Баг | Отклонение фактического результата от ожидаемого |
| Регрессия | Повторная проверка после изменений |
| Smoke-тест | Быстрая проверка основных функций |

Настройка: **«Не перемешивать первую колонку»** — включена (термины сверху вниз).

## Баллы

5 баллов, зачёт при полностью верном сопоставлении.

## Эталон ответа студента

`mapping = [0, 1, 2, 3]` — каждый термин сопоставлен с правильным определением по порядку в редакторе.
