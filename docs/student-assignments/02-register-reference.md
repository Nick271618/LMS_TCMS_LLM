# Эталон (преподаватель). Задание 2 — Регистрация

## Эталон A — успешная регистрация

| Поле | Текст |
|------|-------|
| **Название** | Регистрация нового студента с автоматическим входом |
| **Предусловия** | Email `new.user@demo.test` не занят. Открыта `/register`. |
| **Шаги** | 1. Email: `new.user@demo.test`<br>2. Имя: `Иван Тестов`<br>3. Пароль: `SecurePass1`<br>4. Подтверждение пароля: `SecurePass1`<br>5. Роль: «Студент»<br>6. Нажать «Зарегистрироваться» |
| **Ожидаемый результат** | URL `/`; приветствие содержит «Иван Тестов»; в меню доступен выход; повторная регистрация с тем же email невозможна. |
