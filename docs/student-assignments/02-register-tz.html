Задание 2. Регистрация нового пользователя

Форма /register: Email, Имя (2–50 символов), Пароль (≥8), Подтверждение пароля, Роль (Студент/Преподаватель).

Выберите один сценарий

Успех: уникальный email, корректные поля → пользователь создан, автоматический вход, главная /, приветствие с именем.

  • Занятый email → «Этот email уже зарегистрирован»
  • Пароли не совпадают → «Пароли не совпадают»
  • Короткий пароль (<8) → «Пароль должен быть не короче 8 символов»

Не тестировать: подтверждение по почте, CAPTCHA.
